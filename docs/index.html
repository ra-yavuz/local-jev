local-jev

Run a local Jev-shaped decision API over small GGUF models.

Source Releases Install

What It Is

local-jev is a small local service for typed decisions: yes or no, multiple choice, and ordered ratings. It is not official TypeSafe Jev. It runs local GGUF models through llama.cpp and reads the answer option probabilities from logits instead of generating prose.

Local by defaultRuns on your machine after downloading a GGUF model.
Kev-style APIAccepts POST /v1/systemone requests.
Small setupCreates its own venv and model directory under your home folder.

Quickstart

sudo apt install ./local-jev_*.deb
local-jev setup
local-jev serve

The default server listens on 127.0.0.1:8010.

Example

curl -s http://127.0.0.1:8010/v1/systemone \
  -H 'content-type: application/json' \
  -d '{"state":"The deployment completed and health checks passed.",
       "questions":{"success":{"type":"noul",
       "instructions":"Did the deployment succeed?"}}}'
